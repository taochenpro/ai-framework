# Framework Improvement Proposal

## Proposal ID

P-YYYYMMDD-001

## Target

Agent, route, workflow, hook, config, task packet rule, or documentation to change.

## Evidence

Describe the defect, review finding, CI failure, delay, or repeated confusion that motivates the change.

## Proposed Change

State the smallest practical change.

## Expected Benefit

Describe the behavior that should improve.

## Risks

Describe possible downsides, added friction, or false positives.

## Validation Plan

Explain how the change will be tested against a realistic task or past failure.

## Decision

Accepted, rejected, or deferred.

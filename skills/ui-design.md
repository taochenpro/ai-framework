# Skill: UI Design

## Purpose

Design usable, accessible, maintainable user interfaces when a project has a frontend.

## Use When

- A feature includes screens, navigation, forms, dashboards, or interaction states.
- Existing UI needs consistency or usability improvements.
- Acceptance criteria require visual or interaction behavior.

## Steps

1. Identify the user workflow and primary decision points.
2. Reuse existing design system patterns before adding new ones.
3. Define states for loading, empty, error, success, disabled, and permission-limited views.
4. Keep controls familiar and efficient.
5. Verify responsive layout and accessibility-critical behavior.

## Output Standard

- The UI supports the workflow without explanatory clutter.
- Important states are designed and testable.
- Visual decisions align with the project's design system.

# Skill: Self-Improvement

## Purpose

Improve agents, skills, workflows, and automation based on evidence from real work.

## Use When

- Review comments repeat.
- Defects escape tests.
- CI failures recur.
- Agents conflict over ownership.
- A workflow causes delay, confusion, or rework.

## Steps

1. Collect evidence from tasks, reviews, CI, incidents, and progress logs.
2. Identify the agent, skill, workflow, or hook that should change.
3. Write a proposal using `meta/skill-change-proposal-template.md`.
4. Validate the change on a realistic task or past failure.
5. Record the accepted change in `memory/evolution-log.md`.

## Output Standard

- Improvements are based on observed failures, not preference.
- Changes are small, reversible, and recorded.
- Agent instructions become clearer over time.
